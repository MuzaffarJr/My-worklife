# My Worklife — Muzaffar Normurodov Portfolio

Premium personal portfolio combining product design, frontend engineering, cinematic motion and responsive UX.

## Stack
- Next.js
- React
- TypeScript
- Tailwind CSS
- GSAP / ScrollTrigger

## Sections
Hero, About, Expertise, Selected Work, Tech Stack, Contact.

## Development
```bash
npm install
npm run dev
```

## Production
```bash
npm run build
npm start
```

Content is structured around Muzaffar Normurodov's own work and professional positioning.
